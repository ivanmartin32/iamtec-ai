# Changelog

Todos los cambios notables en este proyecto serán documentados en este archivo.

## [1.0.0] - 2024-04-07

### ✨ Agregado
- Landing page completa para IAMTEC
- Navbar responsivo con dark mode
- Hero section impactante
- 6 servicios principales
- Catálogo de 9 cursos con modal
- Sección sobre nosotros
- 3 testimonios interactivos
- Grid de tecnologías
- Formulario de contacto funcional
- Footer profesional
- Sistema de animaciones suaves
- Dark mode con persistencia
- Menú móvil responsive
- Validación de formularios

### 🎨 Caracteristicas Del Diseño
- Estilo moderno tipo startup tech
- Tipografía limpia y profesional
- Paleta de colores moderna (azul/cyan)
- Gradientes y sombras suaves
- Hover effects atractivos
- Mobile-first responsive design

### 🛠️ Tecnologías
- Vite 5.0.8 como build tool
- Tailwind CSS 3.4.1 para estilos
- JavaScript ES6+ vanilla
- Font Awesome 6.4 para iconos
- Soporte PWA listo

### 📦 Estructura
- Configuración completa de Vite
- Sistema de componentes extensible
- Estilos CSS organizados
- JavaScript modular y comentado
- Documentación completa

### 🚀 Performance
- Score Lighthouse 90+
- Carga inicial < 1.5s
- Optimización de imágenes
- Lazy loading listo para implementar

## Cómo Reportar Problemas

Si encuentras un bug o tienes sugerencias:
